SIMPLE WORKFLOW
---------------
1. Extract PP9-MASTER-FULL-GIT-READY.zip.
2. Open the PP9-MASTER folder in CMD.
3. Run: git status
   It should recognise the existing Git repository because .git is included.
4. Run: npm install
5. Run: npm run build
6. If build succeeds:
   git add .
   git commit -m "PP9 master Tirzepatide and admin customer upgrade"
   git push origin main

No copying files into another project folder is required.
